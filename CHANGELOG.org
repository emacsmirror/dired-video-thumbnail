This document contains the release notes for each tagged commit on the
project's main git repository: [[https://github.com/captainflasmr/dired-video-thumbnail]]

* Versions

** Unreleased

Per-directory settings

Sort order, filters and the thumbnail display height are now remembered per directory in that directory's `.dir-locals.el` and restored when the gallery is reopened. Only the package's own variables are written; other entries and classes in the file are preserved. Two new options, `dired-video-thumbnail-default-filter` and `dired-video-thumbnail-default-display-height`, provide directory-wide defaults, and `dired-video-thumbnail-save-dir-settings` turns persistence off. The gallery's video lists are now buffer-local.

Keybinding alignment (breaking change)

`g` now re-scans the source directory and refreshes the display, matching Dired's `g`, and `G` performs a hard refresh that clears the cached thumbnails for the gallery, re-scans and regenerates them. The single-thumbnail regenerate command moved to `C-r`; the regenerate-all command remains available as `C-R` in the transient menu. The transient display submenu moved from `v` to `V`, freeing `v` for move-to-directory. Existing keybindings for `g` and `G` therefore change behaviour.

Recentering and nearest-thumbnail navigation

`C-l` now re-centres the thumbnail grid around the video at point, cycling between centre, top and bottom like `recenter-top-bottom`. Snapping point to a thumbnail now uses property-change boundaries and a nearest-thumbnail search, so point always lands on a real video even in gaps between rows.

Trash, delete-and-next and move-to-directory

Deleting a video now moves it to the system trash instead of removing it permanently. `C-d` deletes the video at point and stays on the next thumbnail, removing just that thumbnail from the grid without a full refresh. `v` moves the marked videos (or the video at point) to a target directory, creating it when needed and confirming before overwriting existing files. The new =dired-video-thumbnail-auto-accept= option skips these confirmations. Deleting now also removes files from the buffer's master list, so they no longer reappear after a refresh.

Current-thumbnail highlight

The thumbnail at point is now outlined with the new `dired-video-thumbnail-current-thumbnail' face, and the cursor is recoloured to match. The outline is drawn inside the thumbnail so navigating never changes the thumbnail sizes or re-flows the grid, and its colour follows the active theme's `highlight' background unless the face pins an explicit colour. Both effects can be disabled with `dired-video-thumbnail-highlight-current-thumbnail' and `dired-video-thumbnail-highlight-cursor'.

Asynchronous video metadata

Video information (resolution and duration) is now queried with ffprobe asynchronously, up to four processes at a time, instead of one blocking `shell-command-to-string' call per file. Results fill the cache and update the header line as they arrive; buffers sorted or filtered by duration are re-sorted and re-filtered once the queue drains. Failed queries are retried at most three times per file version (tracked by modification time), and a rewritten file is queried again. Background refreshes no longer steal focus from the current window.

Enhanced header line

The header line now shows the visible/total video counts, the marked count, the directory, the current file's name, human-readable size, resolution and duration, plus the current sort order and active filters. The two plain-text status lines that used to sit above the thumbnails are gone, so the buffer contains only thumbnails. File sizes are formatted with `file-size-human-readable`, and size filters use the same format.

Faster, single-pass marking

Marking now builds the set of marked files in a single pass over the Dired buffer and caches the marked count, instead of rescanning Dired once per thumbnail. Marking or unmarking a video repaints only that thumbnail rather than rebuilding the whole grid, and mark-all/toggle-all operate in one pass over Dired. Thumbnails that finish generating in the background keep their marked border.

** <2025-12-15 Mon> 0.3.0

Added transient menu interface

Introduced a comprehensive transient menu (=dired-video-thumbnail-transient=) providing quick access to all commands via =.= or =C-c .= in the thumbnail buffer. The menu displays current state (sort order, filters, video count, recursive/wrap mode) and organises commands into logical groups: Navigation, Playback, Sorting, Filtering, Marking, Delete, Display, and Other.

** <2025-12-15 Mon> 0.2.0

Enhanced package with sorting, filtering, and docs

Added sorting and filtering features to =dired-video-thumbnail=. Introduced customizable options for sorting and filtering criteria, and implement interactive commands for toggling these settings. Included comprehensive documentation in Texinfo format, covering installation, usage, and customization.
